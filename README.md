# PlayStation 5 Product Landing Page

A responsive product landing page built for **freeCodeCamp's Responsive Web Design Certification** (Product Landing Page project).

## About This Project

This project was created to fulfill freeCodeCamp's certification requirements for building a product landing page with a fixed navigation bar, an embedded video, and a working sign-up form. **PlayStation 5 was chosen
purely as design inspiration** — a real, well-known product line gave me something concrete to design around while practicing layout, responsiveness, and interactivity.

## Features

- Fixed navigation bar with a scroll-triggered color transition (JavaScript + CSS)
- Embedded YouTube video section
- Responsive product card layout for controllers, consoles, and accessories
- Email sign-up form

- HTML5
- CSS3 (Flexbox)
